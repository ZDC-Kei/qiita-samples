# 現在地マップ

Qiita記事「GitHub Copilotに相談しながらFlutterで現在地マップを作ってみる」のサンプルです。

## 1. 開発環境を準備する

この段階では、まだプログラムを書きません。まず、Windows向けFlutterアプリの環境構築についてCopilotに相談します。

```text
FlutterでWindows向けのアプリ開発をするから、環境構築について教えてください。
```

この質問への回答を確認しながら、Flutter SDKやWindows向けの開発環境を準備します。

### 今回のゴール

- Flutter SDKなど、開発に必要な環境を確認する
- Windows向けFlutterアプリを起動できる状態にする

### 今回の対象外

- 地図の表示
- 現在位置の取得
- ルート検索

次の段階では、Flutterを使うための開発環境を確認します。
